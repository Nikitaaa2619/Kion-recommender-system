# Объединение кандидатов: до 100 от каждого источника

## Конфигурация

- Популярность: до 100 объектов.
- ALS: до 100 объектов, модель с 32 факторами.
- Item-to-item: до 100 объектов, граф с 50 соседями на объект.
- Просмотренные в train объекты исключаются.
- Повторы между источниками объединяются.
- Для Cold используется только популярность.

## Протокол

Модели построены по train.
Оценка проводится на validation за 2021-08-09 — 2021-08-15.
Test не используется.

Candidate Recall считается по всему набору кандидатов пользователя,
затем усредняется по пользователям с одинаковым весом.
Порядок кандидатов при этой оценке не учитывается.

ALS и item-to-item для Cold имеют пустые собственные наборы.
Fallback для Cold представлен отдельным источником популярности.
